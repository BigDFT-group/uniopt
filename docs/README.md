# UniOpt documentation

The published site is
[bigdft-group.github.io/uniopt](https://bigdft-group.github.io/uniopt/). Its
root also provides
[`llms.txt`](https://bigdft-group.github.io/uniopt/llms.txt) and
[`llms-full.txt`](https://bigdft-group.github.io/uniopt/llms-full.txt).

Choose the page matching your task:

- [User guide](user-guide.md): adopt UniOpt in a Bash command.
- [Runnable demo](../examples/uniopt-demo/README.md): parsing, completion,
  installation, and a local GUI.
- [WISE and ContainerXP previews](../examples/integration-preview/README.md):
  evaluate a larger migration without application side effects.
- [Public API reference](api-reference.md): complete function and declaration
  contract.
- [Bash and JSON schema round trip](schema-round-trip.md): normalized format,
  language bindings, callbacks, safe code generation, and limitations.
- [Distributing a command](distributing-a-script.md): install a program and its
  completion definition.
- [Installation and GUI integration](installation-and-gui.md): install UniOpt
  and build interfaces from JSON.
- [GUI line-advisor design](gui-design.md): generic runner, native and web
  backend, `--gui` hook, validation, and execution contract.
- [Bash 3.2 compatibility](bash-3.2-compatibility.md): supported shell baseline
  and result API.
- [Integration reference audit](integration-reference-audit.md): modeled WISE
  and ContainerXP interfaces and known differences.
- [Test coverage](test-coverage.md): requirement-to-test map and platform limits.
- [Release and publication](releasing.md): prepare and publish the standalone
  repository.
